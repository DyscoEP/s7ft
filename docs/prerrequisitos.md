# Requisitos de uso

- Windows 10/11 de 64 bits.
- Conexión Ethernet con acceso a la red del PLC.
- Dirección IP de la PC compatible con la subred del equipo.
- Permisos de comunicación adecuados en el PLC.
- Permisos de administrador para preparar comunicaciones o ajustar la interfaz de red. Los asistentes pueden solicitar reinicio e interrumpir brevemente la red.

## Preparar comunicaciones

Ejecuta **S7FT.exe**, abre **Ayuda → Preparar comunicaciones Siemens** y sigue el asistente. Revisa los componentes seleccionados y completa las indicaciones de instalación y reinicio antes de consultar el equipo.

El descubrimiento Ethernet puede requerir un controlador adicional. Sigue la indicación del programa si el controlador no está disponible. Puedes crear una conexión directamente con la IP del PLC.

## Compatibilidad

Las consultas y operaciones dependen de la CPU, firmware, configuración y permisos. La detección de un equipo no implica autorización para leer memoria, escribir o transferir bloques.

Consulta [la guía](guia-de-uso.md) y [compatibilidad y ayuda](limitaciones-y-problemas.md). Los componentes de terceros conservan las condiciones indicadas en [los avisos de licencia](../THIRD-PARTY-NOTICES.txt).
